# 🛒 Desktop Wholesale Application

A Windows-based desktop application for managing wholesale transactions, built using **C# Windows Forms** and **LINQ to SQL**. This project was created during a high school practical assessment based on a pre-configured Microsoft SQL Server (SSMS) database schema.

> 💡 **Developer's Note:**  
> This project highlights my early experience with C# desktop application development, object-relational mapping (ORM) via LINQ to SQL, and handling complex multi-user workflows (Buyers & Vendors) under time-constrained exam/competition conditions.

### 🌟 High-Level Overview
* **Dual-User System:** Tailored workflows for Buyers (purchase management) and Vendors (supply/catalog management) without a centralized admin role.
* **LINQ to SQL Data Layer:** Utilizes type-safe queries and ORM mappings to interact with the pre-built SQL Server database.
* **Windows Forms UI:** Desktop interface designed for quick data entry, grid views, and transactional operations.

### 🛠️ Tech Stack
* **Framework & UI:** C# (.NET / Windows Forms)
* **Data Access:** LINQ to SQL
* **Database:** Microsoft SQL Server (SSMS)
